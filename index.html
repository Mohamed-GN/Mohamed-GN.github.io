Lead Embedded Architect

Sep 2024 – Present
Hexa5

Lead architect and technical owner of a production-grade inline Ethernet encryption platform designed for high throughput, multi-peer operation and low latency, targeting 1 Gb/s full-duplex (2 Gb/s aggregate) on Zephyr RTOS.

  • Selected the target SoC (RISC-V Microchip PolarFire SoC) and defined the embedded software architecture.
  • Reworked the existing RISC-V Zephyr port for PolarFire SoC from machine mode to supervisor mode, so that Microchip’s HSS (Hart Software Services) is the only firmware running in machine mode.
  • Built a compact libcrypto for Zephyr RTOS and loaded the OpenSSL FIPS provider through LLEXT (loadable extensions), with all FIPS self-tests passing; fully integrated it into Zephyr as one of its PSA Crypto wrappers.
  • Integrated NIST’s ACVP client to run known-answer tests (KATs) on the FIPS provider.
  • Design the high-throughput data plane: a polling-based Ethernet packet path that removes interrupt overhead to meet throughput and latency requirements, with software architecture and data movement (DMA, DDR) coordinated with the FPGA team responsible for AES-GCM-256 hardware acceleration.
  • Design and implement the control plane (handshake procedures, key management and encryption control), which commands the data plane through a precisely defined state machine.
  • Implement MQTTS (MQTT over TLS) cloud management on Zephyr, plus supporting product services: alarms, shell/CLI and logging.

04 / FEATURED PROJECT

High-performance Ethernet encryption

A production embedded networking system combining high-throughput packet processing, FPGA-accelerated cryptography, hardware/software co-design and a FIPS-oriented software stack.

EMBEDDED SYSTEMS · DATA PLANE · FPGA

Inline Ethernet Encryptor

Lead architect of an embedded Ethernet encryption platform for multi-peer, full-duplex operation and low-latency packet processing. It combines a RISC-V PolarFire SoC running Zephyr RTOS, a polling-based Ethernet data plane, DMA, and an FPGA-based AES-GCM-256 cryptographic engine.

ThroughputDesigned for 1 Gb/s full-duplex operation and up to 2 Gb/s aggregate traffic.
LatencyArchitecture built around low-latency packet processing, with polling instead of interrupts.
PlatformZephyr RTOS on RISC-V Microchip PolarFire SoC, in supervisor mode with HSS in machine mode.
CryptographyFPGA-accelerated AES-GCM-256, coordinated with the FPGA team.
Data movementDMA between DDR memory and the FPGA crypto engine.
ArchitectureHigh-performance data plane plus a state-machine-driven control plane (handshake, key management, encryption control).
FIPS software stackOpenSSL FIPS provider loaded through LLEXT as a PSA Crypto wrapper, self-tests passing, ACVP KATs.
ManagementMQTTS cloud management with alarms, CLI and logging.
