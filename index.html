02 / EXPERIENCE

Professional experience

Lead Embedded Architect

Sep 2024 – Present
Hexa5

Lead architect and technical owner of an inline Ethernet encryption appliance targeting 1 Gb/s full-duplex throughput (2 Gb/s aggregate), built on Zephyr RTOS.

  • Selected the target SoC (RISC-V Microchip PolarFire SoC) and defined the Zephyr RTOS software architecture.
  • Reworked the existing RISC-V Zephyr port for PolarFire SoC from machine mode to supervisor mode, so that Microchip’s HSS (Hart Software Services) is the only firmware running in machine mode.
  • Built a compact libcrypto for Zephyr RTOS and loaded the OpenSSL FIPS provider through LLEXT (loadable extensions), with all FIPS self-tests passing; fully integrated it into Zephyr as one of its PSA Crypto wrappers.
  • Integrated NIST’s ACVP client to run known-answer tests (KATs) on the FIPS provider.
  • Design the data plane: a polling-based Ethernet packet path that removes interrupt overhead to meet throughput and latency requirements, with hardware/software integration coordinated with the FPGA team for AES-GCM-256 acceleration (DMA and DDR data movement).
  • Design and implement the control plane (handshake procedures, key management and encryption control), which commands the data plane through a precisely defined state machine.
  • Implement MQTTS (MQTT over TLS) cloud management on Zephyr, with alarms, CLI and logging.

04 / FEATURED PROJECT

High-performance Ethernet encryption

An embedded networking system combining a high-throughput data plane, FPGA-accelerated cryptography and a FIPS-oriented software stack.

EMBEDDED SYSTEMS · DATA PLANE · FPGA

Inline Ethernet Encryptor

Lead architect of an inline Ethernet encryption appliance for multi-peer, full-duplex operation with low-latency packet processing. The system combines a RISC-V PolarFire SoC running Zephyr RTOS, a polling-based Ethernet data plane, DMA, and an FPGA-based AES-GCM-256 engine.

ThroughputTargeting 1 Gb/s full-duplex and up to 2 Gb/s aggregate traffic.
PlatformZephyr RTOS on RISC-V Microchip PolarFire SoC, running in supervisor mode with HSS in machine mode.
Data planePolling-based Ethernet path with DMA and DDR data movement to the FPGA crypto engine.
Control planeHandshake, key management and encryption control, driving the data plane through a precise state machine.
FIPS software stackOpenSSL FIPS provider loaded through LLEXT as a PSA Crypto wrapper, with self-tests passing and ACVP KATs.
ManagementMQTTS cloud management with alarms, CLI and logging.
